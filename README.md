# URL Chat

URLを相手に送るだけで、同じ部屋でリアルタイムチャットできる小さなWebアプリです。

## 必要なもの

- Node.js 18以上

## 起動

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開き、「チャットルームを作る」を押します。

発行された `/room/xxxxx` のURLを相手に送れば、そのURLから同じチャットに参加できます。

## デプロイ

WebSocketを使うため、WebSocket対応のNode.jsホスティングにデプロイしてください。
Render、Railway、Fly.ioなどが候補です。

## 注意

このサンプルは学習・個人利用向けです。
メッセージはサーバーのメモリ上に保存され、サーバー再起動で消えます。
本番公開する場合は、認証、スパム対策、レート制限、永続DB、通報・削除機能などを追加してください。
