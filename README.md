# Tomodachi Chat

6桁のルームナンバーを使って入室する、シンプルなリアルタイムグループチャットです。PC・スマートフォンのブラウザに対応しています。

## 起動方法

必要：Node.js 18以上

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

1. 名前を入力して「新しいルームを作る」を押すと、6桁の番号が発行されます。
2. 友だちには、その6桁の番号を伝えます。
3. 友だちは同じサイトを開き、自分の名前とルームナンバーを入力して入室します。
4. 同じルームの参加者同士でリアルタイムに会話できます。

## データ保存について

- チャットサーバー上の履歴はメモリに保存され、直近100件を保持します。
- ブラウザ側には、その端末で受信した履歴を最大100件保存できます。
- Renderの再起動や再デプロイでサーバー上のルームと履歴は消えます。
- ブラウザ内の保存は端末・ブラウザごとであり、サーバーに保存された共有履歴ではありません。

永続的な履歴が必要なら、Render PostgreSQL等のデータベースを接続してください。

## Renderへのデプロイ

このリポジトリはNode.js Web Serviceとして動作します。

- Build Command: `npm install` または `yarn`
- Start Command: `npm start` または `yarn start`

WebSocket通信に対応したWeb Serviceを使ってください。GitHubのmainブランチに変更をコミットすると、Renderの自動デプロイ設定によって反映されます。

## セキュリティ・運用上の注意

このサンプルは学習・個人利用向けです。ルームナンバーを知っている人は入室でき、認証・招待制アクセス制御・スパム対策・レート制限は実装されていません。ルーム番号は秘密のパスワードではありません。個人情報や機密情報を送信しないでください。

公開運用前には、認証、ルーム参加権限、レート制限、通報・削除機能、データベースへの永続保存を追加してください。
