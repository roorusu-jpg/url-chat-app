# Friend Chat

## v1.1.0
- Neon PostgreSQLにルーム、直近100件のメッセージ、写真、既読数を保存。
- Renderの再起動・再デプロイ後もルーム番号とチャット履歴を復元。
- 公式コミュニティルーム `080002` をデータベース上で常設。

## v1.0.4
- INFINITY WORKS II の公式コミュニティルーム `080002` をサーバー起動時に自動作成し、常設。
- Friend Chat のトップページから公式交流所へ参加できる案内を追加。
- サーバー再起動後もルーム番号 `080002` は自動で復旧。


6桁のルームナンバーを使って入室する、シンプルなリアルタイムグループチャットです。PC・スマートフォンのブラウザに対応しています。

## 起動方法

必要：Node.js 18以上

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

1. 名前を入力して「新しいルームを作る」を押すと、6桁の番号が発行されます。
2. 友だちには、その6桁の番号を伝えます。
3. 友だちは同じサイトを開き、自分の名前とルームナンバーを入力して入室します。
4. 同じルームの参加者同士でリアルタイムに会話できます。

## データ保存について

- Neon PostgreSQLにルームとメッセージを保存し、各ルーム直近100件をサーバーから復元します。
- 写真データと既読情報もメッセージと一緒に保存します。
- `DATABASE_URL` が未設定の場合は開発用の一時メモリ保存に切り替わります。
- ブラウザ側の保存機能は端末ごとのバックアップとして引き続き利用できます。
- Neonのデータベースに保存された履歴は、Renderの再起動・再デプロイでは消えません。

## Renderへのデプロイ

このリポジトリはNode.js Web Serviceとして動作します。

- Build Command: `npm install` または `yarn`
- Start Command: `npm start` または `yarn start`

WebSocket通信に対応したWeb Serviceを使ってください。GitHubのmainブランチに変更をコミットすると、Renderの自動デプロイ設定によって反映されます。

## セキュリティ・運用上の注意

このサンプルは学習・個人利用向けです。ルームナンバーを知っている人は入室でき、認証・招待制アクセス制御・スパム対策・レート制限は実装されていません。ルーム番号は秘密のパスワードではありません。個人情報や機密情報を送信しないでください。

公開運用前には、認証、ルーム参加権限、レート制限、通報・削除機能、データベースへの永続保存を追加してください。
